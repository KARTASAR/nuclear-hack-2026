# Пакет `raman_hack`

Основной код проекта находится здесь.  
Пакет организован по слоям пайплайна: данные -> preprocessing -> модели -> валидация -> трекинг.

## Подпапки

- `data/` — парсинг исходных `.txt`, индексация и сборка датасета/таблиц признаков.
- `preprocess/` — очистка и нормализация спектров (baseline correction, despike, outlier handling и т.д.).
- `models/` — реализация классических и DL-моделей, train/inference-обвязка для Torch.
- `metrics/` — расчет метрик классификации.
- `validation/` — split-политики и процедуры оценки без leakage.
- `runner/` — orchestration полного запуска эксперимента.
- `tracking/` — сохранение run-артефактов и сводных таблиц.
- `interpretation/` — интерпретация информативных спектральных диапазонов (inverse task).
- `experimental/` — изолированные экспериментальные компоненты, не влияющие на основной поток.

## Где смотреть входные точки

- Конфигурация: `src/raman_hack/config.py`
- Основной запуск: `src/raman_hack/runner/experiment.py`
- CLI-обвязка находится в `scripts/`.
