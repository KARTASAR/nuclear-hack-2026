# Raman XAI Pipeline Usage

## Что уже реализовано

В `src/raman_hack` реализован production-oriented XAI pipeline для torch-моделей v1:

- сохранение fold/final checkpoints и состояния препроцессинга;
- raw explainers:
  - `integrated_gradients`
  - `gradcam1d`
  - `lrp`
  - `attention_rollout`
  - `gradient_attention_rollout`
- band-level validation:
  - crop-aware biochemical band registry
  - `corr(R, I)`
  - `corr(R, I^2)`
  - normalized relevance-per-energy
  - artifact relevance fraction
  - cross-method concordance
- сериализация raw/validated artifacts в `experiments/runs/<run_id>/interpretability/...`
- поддержка `raman_moe` с sector-aware атрибуциями (`sector_gates`)

## Runner-level запуск

Если в конфиге включить блок:

```yaml
explainability:
  enabled: true
  methods: [integrated_gradients]
  target_models: [folds, final]
  sample_limit: 16
  save_raw: true
  save_validation: true
```

то после обычного запуска (конкретный рабочий конфиг):

```bash
# canonical (script-path)
.venv/bin/python experiments/scripts/run_experiment_v1.py \
  --config experiments/configs/experiment/xai/xai_1500_resnet1d_ref.yaml

# equivalent (module)
.venv/bin/python -m experiments.scripts.run_experiment_v1 \
  --config experiments/configs/experiment/xai/xai_1500_resnet1d_ref.yaml
```

runner автоматически:

1. обучит torch-модель по CV;
2. сохранит `models/folds/*` и `models/final/*`;
3. построит raw explanations;
4. выполнит band-level + physics-aware validation;
5. положит артефакты в `experiments/runs/<run_id>/interpretability/`.

## Ручной запуск после уже существующего run

Выбрать последний run и построить raw explanations:

```bash
RUN_DIR="$(find experiments/runs -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)"

# canonical (script-path)
.venv/bin/python experiments/scripts/explain_batch.py \
  --run-dir "$RUN_DIR" \
  --methods integrated_gradients gradcam1d \
  --target-models folds final \
  --sample-limit 4

# equivalent (module)
.venv/bin/python -m experiments.scripts.explain_batch \
  --run-dir "$RUN_DIR" \
  --methods integrated_gradients gradcam1d \
  --target-models folds final \
  --sample-limit 4
```

Построить validation reports:

```bash
# canonical (script-path)
.venv/bin/python experiments/scripts/validate_explanations.py \
  --run-dir "$RUN_DIR"

# equivalent (module)
.venv/bin/python -m experiments.scripts.validate_explanations \
  --run-dir "$RUN_DIR"
```

## Ограничения

- `gradcam1d` ориентирован на CNN-путь и не применяется к `ramannet`.
- `lrp` в текущей версии реализован как dependency-free epsilon-LRP style input relevance, достаточный для band-level анализа, но не как полный layer-by-layer engine для всех архитектур.
- `raman_moe` в этой итерации поддерживает обязательный XAI-набор `integrated_gradients + sector_gates`; Grad-CAM/LRP для MoE не включены.
