# Wave2 + Dual-Window Results (2026-03-06)

## 1) Что запустили

Полный sweep `configs/experiment/wave2_file_mean/*`:

- 2 окна (`1500`, `2900`);
- 2 preprocessing-набора на окно;
- 3 model family (`catboost`, `logreg`, `svm_rbf`);
- всего 12 конфигов (5-fold group CV).

## 2) Ключевые результаты wave2

Лучшие `macro_f1` по уникальным конфигам wave2:

1. `w2_1500_file_mean_arpls_emsc_catboost`  
   `run_id=20260306_164747_w2_1500_file_mean_arpls_emsc_catboost`

2. `w2_1500_file_mean_arpls_msc_catboost`

3. `w2_2900_file_mean_airpls_snv_logreg`  
   `run_id=20260306_170025_w2_2900_file_mean_airpls_snv_logreg`  
   `macro_f1=0.3682`, `balanced_acc=0.3742`

Наблюдения:

- В `wave2` лучшим на `1500` остаётся `catboost`.
- На `2900` в этой 5-fold постановке `catboost` просел, лучший здесь оказался `logreg`.
- Стек `airpls + emsc` на `2900` показал слабые результаты.
- Для `logreg` на части конфигов виден `ConvergenceWarning` (даже при `max_iter=3000`).

## 3) Dual-window late fusion

### 3.1 Fusion на лучших исторических single-run (из `s1_*`)

Команда:

```bash
.venv/bin/python experiments/scripts/dual_window_fusion_v1.py \
  --runs-root experiments/runs \
  --alpha-step 0.05 \
  --output experiments/docs/artifacts/fusion_sweep_default.csv

.venv/bin/python -m experiments.scripts.dual_window_fusion_v1 \
  --runs-root experiments/runs \
  --alpha-step 0.05 \
  --output experiments/docs/artifacts/fusion_sweep_default.csv
```

Автовыбранные run’ы:

- `1500`: `20260306_154617_s1_1500_file_mean_arpls_msc`
- `2900`: `20260306_155938_s1_2900_file_mean_airpls_snv`

Лучший fusion:

- `alpha_1500=0.40`, `alpha_2900=0.60`
- `macro_f1=0.4687`
- `balanced_acc=0.4742`
- `accuracy=0.4831`

Это выше лучшего single-window по `macro_f1` (`0.4569`).
