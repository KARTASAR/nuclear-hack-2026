Проверить **все перспективные архитектуры**, упомянутые в обзоре/статьях и в обсуждении, чтобы не потерять потенциально лучший подход до финального тюнинга.

## 3) Что ещё добавляем (новые архитектуры)

Ниже полный список для этой волны (в порядке внедрения).

### A1. Inception-1D (multi-kernel spectral CNN)

Идея:

1. параллельные ветки Conv1D с разными kernel size (`3/5/9/15`);
2. concatenate + residual shortcut;
3. global pooling + linear classifier.

Зачем:

1. хорошо ловит пики разной ширины;
2. low-risk и быстро обучается.

### A2. 1D-DRSN (Deep Residual Shrinkage Network)

Идея:

1. residual-блоки с soft-thresholding/shrinkage;
2. подавление шумовых компонент прямо в feature space.

Зачем:

1. для шумных Raman сигналов это часто даёт устойчивость.

### A3. 1D-EfficientNet-lite

Идея:

1. MBConv-like блоки + depthwise separable conv;
2. squeeze-excitation;
3. компактный inference.

Зачем:

1. хороший quality/runtime баланс;
2. может дать gain при ограниченном времени.

### A4. Single-step preprocessing CNN (Residual preprocessor + classifier)

Идея:

1. learnable preprocessor (1D residual denoiser/baseline suppressor);
2. далее classifier head (например `ramannet`).

Зачем:

1. проверка литературы по end-to-end preprocessing.

### A5. Single-step preprocessing U-Net1D + classifier

Идея:

1. U-Net-like 1D preprocessor для восстановления/очистки спектра;
2. classifier (`spectral_transformer` или `ramannet`) поверх очищенного сигнала.

Зачем:

1. альтернативная single-step схема (более мощный preprocessor).

## 6) Протокол запуска (обязательный)

### 6.1 Phase 0: correctness

1. `pytest` smoke для новых `model_family`.
2. 1 короткий run на мини-конфиге для каждого нового семейства.

### 6.2 Phase 1: architecture gate (быстрый отбор)

Для каждой новой архитектуры:

1. run на `1500` (1 seed);
2. run на `2900` (1 seed);
3. сравнение с текущими winners по `macro_f1`.

Проходит дальше только если:

1. не хуже winner больше чем на `0.01`,  
или
2. лучше winner минимум на `+0.005`.

### 6.3 Phase 2: stability gate

Для прошедших кандидатов:

1. `split_seed=11/22/33`;
2. считаем mean/std.

Проходит дальше только если:

1. `macro_f1_mean` выше baseline;
2. `std` не хуже текущих победителей критически.

### 6.4 Phase 3: fusion gate

Для лучших по окнам:

1. fusion sweep (`alpha-step=0.05`, затем `0.01` для топ-пары);
2. сравнение с текущим DL-fusion baseline.

## 7) Stop-rules (чтобы не потерять время)

1. Любая архитектура без сигнала в Phase 1 сразу отклоняется.
2. Если прирост меньше шума по seed — отклоняется.
3. На тюнинг уходит только top-2 кандидата после stability.

## 8) Порядок реализации (очередь работ)

1. Implement A1 (Inception1D) -> gate 1500/2900.
2. Implement A2 (DRSN1D) -> gate 1500/2900.
3. Implement A3 (EfficientNet1D-lite) -> gate 1500/2900.
4. Implement A4 (Single-step residual preprocessor) -> gate 1500/2900.
5. Implement A5 (Single-step U-Net preprocessor) -> gate 1500/2900.
6. Stability only for passed models.
7. Fusion only for passed models.

## 11) Критерий финального решения

Новый стек принимается, если:

1. `macro_f1_mean` > текущего DL-кандидата;
2. `balanced_accuracy_mean` не падает;
3. variance приемлема;
4. runtime не убивает iteration speed.
