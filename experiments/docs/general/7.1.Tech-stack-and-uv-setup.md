# Зафиксированный стек и установка через `uv`

Дата фиксации: `2026-03-06`

## 1. Базовый стек (v1)

Основной стек для первой версии:

1. `numpy`, `scipy` — спектральная математика и численные преобразования.
2. `polars`, `pyarrow` — табличная обработка и хранение промежуточных датасетов в parquet.
3. `scikit-learn` — baseline-модели и group-wise валидация.
4. `catboost` — основной сильный tabular baseline для multiclass.
5. `pybaselines` — расширенные baseline-алгоритмы (`AsLS`, `SNIP`, morphological family).
6. `torch` — DL-эксперименты (вторая волна).
7. `hydra-core`, `omegaconf` — конфиги экспериментов и reproducible overrides.
8. `loguru` — логирование.

Примечание:

- `pandas` пока оставляем как transitional dependency для совместимости существующих модулей.
- Новый код для data/experiment слоя стараемся писать на `polars`.

## 3. Установка через `uv`

Все команды ниже выполняются из корня репозитория: `nuclear-hack-2026/`.

### 3.1 Создать виртуальное окружение

```bash
uv venv .venv
```

### 3.2 Установить зависимости

```bash
uv pip install --python .venv/bin/python -r requirements.txt
```

### 3.3 Установить проект в editable-режиме

```bash
uv pip install --python .venv/bin/python -e .
```

### 3.4 Проверить окружение

```bash
.venv/bin/python -V
.venv/bin/python -c "import polars, catboost, torch; print('ok')"
```

## 4. Правило обновления стека

Если добавляем новую ключевую библиотеку:

1. Обновить `requirements.txt`.
2. Обновить `pyproject.toml`.
3. Обновить этот файл короткой записью, зачем добавили зависимость.
