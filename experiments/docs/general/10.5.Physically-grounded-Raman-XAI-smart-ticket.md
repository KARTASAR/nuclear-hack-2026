## Compatibility and Path Policy

- Canonical artifact root for this layer is `experiments/runs/<run_id>/...`.
- Explainability artifacts are written under `experiments/runs/<run_id>/interpretability/...`.
- The script-path and module-path CLIs are both supported and covered by tests.

## Runtime Usage (Current)

Resolve a concrete run directory and execute explainability export:

```bash
RUN_DIR="$(find experiments/runs -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)"

# canonical (script-path)
.venv/bin/python experiments/scripts/explain_batch.py \
  --run-dir "$RUN_DIR" \
  --methods integrated_gradients gradcam1d \
  --target-models folds final \
  --sample-limit 4

# equivalent (module)
.venv/bin/python -m experiments.scripts.explain_batch \
  --run-dir "$RUN_DIR" \
  --methods integrated_gradients gradcam1d \
  --target-models folds final \
  --sample-limit 4
```

Expected outputs:

- `experiments/runs/<run_id>/interpretability/raw/<method>/<target_model>/sample_*.json`
- `experiments/runs/<run_id>/interpretability/raw/<method>/<target_model>/sample_*.parquet`
- `experiments/runs/<run_id>/interpretability/raw/<method>/<target_model>/sample_*.png`
