## Canonical Output Policy

- Canonical output root is `experiments/runs/<run_id>/...`.
- Validation outputs are written to `experiments/runs/<run_id>/interpretability/validation/...`.
- Legacy `runs/...` shorthand may appear in older historical notes, but current-state usage in this file is fully qualified with `experiments/runs/...`.

## Implemented Validation Outputs

- `experiments/runs/<run_id>/interpretability/validation/sector_summary.csv`

## Implemented Metrics and Checks

Global/physics-aware diagnostics include:

- `corr(R, I)`
- `corr(R, I^2)`
- normalized relevance-per-energy
- artifact relevance fraction

Cross-method consistency includes:

- method concordance over shared samples

Domain constraints include:

- crop-aware registry behavior for `1500` and `2900`
- explicit artifact masking and warning surfaces in report output

## Runtime Usage (Current)

```bash
RUN_DIR="$(find experiments/runs -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)"

# canonical (script-path)
.venv/bin/python experiments/scripts/validate_explanations.py \
  --run-dir "$RUN_DIR"

# equivalent (module)
.venv/bin/python -m experiments.scripts.validate_explanations \
  --run-dir "$RUN_DIR"
```
