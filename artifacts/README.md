# Артефакты

Папка для упакованных результатов, которые нужны для inference/submission.

## Что здесь лежит

- `submission_pack_v1/` — готовый inference-pack:
  - `manifest.json` — описание стратегий и маппинг на артефакты моделей;
  - `models_index.csv` — индекс моделей в паке;
  - дополнительные файлы моделей/метаданных.

## Назначение

- Используется скриптами из `scripts/inference/`.
- Позволяет запускать предсказание без повторного обучения моделей.

Подробно: `docs/SUBMISSION.md`.
