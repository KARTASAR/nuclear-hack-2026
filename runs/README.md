# Папка `runs`

Здесь сохраняются артефакты всех запусков экспериментов.

## Типовое содержимое одного run

- `config_resolved.yaml` — финальный конфиг запуска.
- `metrics.json` — агрегированные метрики.
- `predictions.parquet` — предсказания по объектам.
- `sample_meta.parquet` — метаданные сэмплов для анализа.
- `run_meta.json` — служебная информация о запуске.
- дополнительные CSV/PNG/отчеты в зависимости от сценария.

## Назначение

- локальный трекинг качества и сравнение гипотез;
- вход для battery/dev-lock/sweep-скриптов.

## Важно

- обычно это рабочая папка большого объема;
- рекомендуется не коммитить ее целиком в репозиторий;
- для публикации оставлять только нужные итоговые артефакты/срезы.
